# 🎵 Statify UI

**Statify UI** is the frontend of **Statify**, built with **Next.js**, providing a clean and simple interface to visualize your personalized Spotify statistics.

It consumes the Statify API and focuses on speed, simplicity, and a smooth user experience.

---

## 🚀 Technologies

- ⚛️ React
- ▲ Next.js
- 🎵 Spotify Web API (via Statify API)

---

## 🛠️ Installation & Run

```bash
# Install dependencies
npm install

# Run development server
npm run dev

Open your browser at:
👉 http://localhost:3000
```
